# Guía de Usuario

## Bienvenido al Sistema de Gestión de Pedidos

Esta herramienta le permite gestionar clientes, pedidos y obtener insights automatizados para su negocio.

## Funciones Principales

1. **Gestión de Clientes**: Ingrese y administre la base de clientes de su negocio.
2. **Gestión de Pedidos**: Registre nuevos pedidos asociados a clientes, marque sus estados (pendiente, completado, cancelado) y administre el flujo de trabajo.
3. **Análisis con IA**: Utilice la inteligencia artificial para analizar el historial de sus pedidos y obtener recomendaciones (ej: qué productos se venden más, ideas para promociones).

## Pasos Iniciales
- **Iniciar sesión**: Debe ingresar con su cuenta para acceder al sistema.
- **Crear un cliente**: Antes de registrar un pedido, asegúrese de tener al menos un cliente en el sistema.
- **Crear pedido**: Asigne montos, estados e información relevante al pedido.
