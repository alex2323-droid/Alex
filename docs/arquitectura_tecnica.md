# Arquitectura Técnica

Este documento describe la arquitectura técnica de la aplicación.

## Componentes Principales
- **Frontend**: React, Vite, Tailwind CSS
- **Backend y Base de Datos**: Firebase (Firestore y Authentication)
- **Inteligencia Artificial**: Google Gen AI SDK (Gemini API)

## Patrones de Diseño
- Arquitectura basada en componentes funcionales de React.
- Gestión de estado global mediante React Context.
- SPA (Single Page Application) para una navegación más rápida.
