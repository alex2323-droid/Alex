# Guía del Usuario

Bienvenido a la guía de usuario de la aplicación. Esta guía te ayudará a entender cómo utilizar el sistema.

## Pasos Iniciales
1. **Inicio de Sesión**: Utilice su cuenta para ingresar a la plataforma.
2. **Panel Principal (Dashboard)**: Aquí encontrará el resumen de sus datos y acceso rápido a las funcionalidades clave.
3. **Interacción AI**: Podrá realizar análisis utilizando el asistente de IA integrado para obtener sugerencias y recomendaciones.
