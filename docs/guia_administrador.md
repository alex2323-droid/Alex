# Guía del Administrador

Bienvenido a la guía de administración del sistema.

## Tareas Administrativas
- **Configuración de variables de entorno**: Asegúrese de configurar correctamente `GEMINI_API_KEY` y las credenciales de Firebase.
- **Gestión de usuarios**: Utiliza la consola de Firebase Authentication para gestionar cuentas de usuario, restablecer contraseñas o deshabilitar accesos.
- **Base de datos**: Monitorea las colecciones de Firestore y ajusta las reglas de seguridad según sea necesario.
- **Despliegue**: El proyecto está configurado para desplegarse utilizando GitHub Actions, con soporte para GitHub Pages en el directorio `docs/`.
